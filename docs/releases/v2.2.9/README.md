# AegisUi v2.2.9 release evidence

This folder accompanies the `v2.2.9` release.

- `screenshots/boot-light-intro.png` — captured from the packaged boot flow.
- `screenshots/osint-overview.png` — captured from the packaged OSINT Analyst
  Deck after its renderer connected.
- `osint-release-preview.html` — a local, reproducible visual companion for
  reviewing the Analyst Deck structure without launching Electron.
- `RELEASE_NOTES.md` — scope, validation and package notes.

The OSINT catalog contains public-source links and controlled external launch
actions only. It does not automate collection, credential access or intrusive
actions.
