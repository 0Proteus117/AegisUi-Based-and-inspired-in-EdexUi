# AegisUi v2.2.9 — Boot Branding & OSINT Analyst Deck

## What changed

- A refined, deterministic AegisUi boot sequence: progressive particle field,
  identity mark, welcome line, breathing glow and one transition into the
  cockpit.
- A full OSINT Analyst Deck replacing the placeholder workspace.
- Nine public-source research domains and 161 curated resource cards.
- Each tool card opens a cockpit detail panel before its external website is
  launched.

## Visual evidence

`osint-release-preview.html` is the reproducible local visual evidence for
this release. It renders the same registry-backed overview and representative
tool-detail composition used by the workspace, without relying on remote
assets. The overview shows the category-first command deck; the detail view
shows how a source is described and intentionally opened only through the
explicit `OPEN WEB` action.

## Scope

The OSINT catalog is deliberately limited to public-source, passive research,
verification, documentation and defensive context. External sources retain
their own terms, rate limits and access controls.
