What is AegisUi?

AegisUi began as a rescue effort.

The original eDEX-UI project was archived and depended on an increasingly outdated software stack that no longer worked reliably on modern Apple Silicon Macs.

The first goal was simple:

Bring eDEX-UI back to life on modern macOS hardware.

Once that objective was achieved, the project evolved far beyond a compatibility update.

AegisUi now focuses on transforming the original science-fiction-inspired interface into a functional workspace that can be used daily for engineering, research, project management and productivity while preserving the visual identity that made eDEX-UI unique.

Key Features

Native Apple Silicon Support

* Native ARM64 application
* Modern Electron stack
* Native ARM64 node-pty
* Updated dependencies throughout the project
* Modern macOS packaging workflow

⸻

Engineering Command Deck

Purpose-built engineering workspace featuring:

* CAD / CAM launchers
* CAE / CFD launchers
* Research sources
* Technical references
* Standards and documentation shortcuts
* Project status overview

⸻

Project Control

Integrated visual project management.

Features include:

* Project creation
* Milestone management
* Progress tracking
* Status assignment
* Reordering and editing
* Automatic backups
* Local-only storage

⸻

Native Calendar Integration

Unlike the original implementation, AegisUi uses a dedicated native EventKit bridge.

Features:

* Week view
* Month view
* Calendar filtering
* Support for recurring events
* iCloud calendars
* Outlook / Exchange calendars
* University and work accounts

⸻

Local Situation Awareness

Integrated cockpit-style information panel:

* Local map
* RainViewer weather radar
* Optional TomTom traffic overlays
* Calendar events
* Project timelines

⸻

Apple Music Integration

Optional Apple Music integration with:

* Metadata display
* Playback controls
* Playlist launching
* Progress tracking
* Album artwork
* Animated visualizer

Apple Music remains completely disconnected until explicitly enabled by the user.

⸻

Native macOS Application Launcher

The original filesystem panel has been replaced by a practical launcher that discovers and launches installed macOS applications directly from the interface.

Privacy

AegisUi follows a local-first approach.

The application does not transmit project data or personal information.

The following remain local to the user’s machine:

* Project timelines
* Project Control data
* Calendar selections
* Apple Music preferences
* Playlist configuration
* Traffic API keys

Nothing is committed to GitHub or transmitted by the application.

⸻

Current Platform Support

AegisUi is currently developed and validated on:

* macOS
* Apple Silicon (ARM64)

Every release is tested on native Apple Silicon hardware.

Other platforms may require additional work and are not currently considered supported targets.
