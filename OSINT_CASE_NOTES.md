# OSINT Case Notes

Case Notes and Evidence Notes are plain local text with generated ids, case id,
optional evidence id, timestamps and normalized tags. Script-like content,
control characters and unsafe HTML are rejected or neutralized before storage.
No Markdown is rendered as unsafe HTML, no remote embed is accepted and no
image/iframe attachment path exists.

Notes are contextual analyst annotations, not provider facts. They are never
sent to Wayback, other providers, Ollama, Assistant memory, Calendar or Project
Timeline.
