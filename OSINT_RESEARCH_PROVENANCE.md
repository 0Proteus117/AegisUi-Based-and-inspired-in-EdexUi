# OSINT research provenance

The UI keeps source origins distinct:

- **DERIVED NORMALIZATION** — URL or DOI normalized locally.
- **PROVIDER OBSERVATION** — fixed Crossref result or explicit Wayback result.
- **LOCAL FILE METADATA** — bounded metadata found in selected PDF bytes.
- **LOCAL INTEGRITY** — SHA-256 of original selected bytes.
- **ANALYST OBSERVATION** — an explicitly entered note, never an extracted fact.

Provider metadata, archive metadata and local PDF metadata are contextual. They
do not prove authorship, publication truth, originality or claim validity.
