# STUD Compute Data and Plots

The Data tool imports a single explicitly selected numeric CSV or TSV. It does
not watch folders, scan directories or preserve the source path. The current
workflow produces column summaries and bounded plot specifications for line,
scatter or histogram presentations.

Each plot requires an explicit title and axis labels. Units are shown only when
the analyst supplies them in the labels or saves a unit-aware calculation; the
workbench never infers engineering units from numbers or filenames. SVG is a
bounded local presentation, not a claim of publication-ready scientific
plotting.
