# OSINT research evidence

Source context uses the existing Evidence Object pipeline. Approved fields can
include source URL/DOI, normalized title/publisher/authors, timestamps, archive
context, selected bounded excerpt, analyst observation, field provenance and a
local PDF original-byte SHA-256.

The preview allows redaction before the canonical Evidence Record is written
and hashed. Raw Crossref/Wayback payloads, full page bodies, entire PDF text,
cookies, local paths and original documents are not persisted.

Original document attachment is deliberately deferred.
